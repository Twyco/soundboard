# Simple Voice Chat Soundboard 0.4.0

## Fixed

- Soundboard key combinations now follow their original keys when moving between
  Minecraft 1.21.11, 26.1.x, 26.2, and 26.3 with Soundboard 0.4.0 installed.
- Existing sound settings, favorites, and volume settings are preserved.

## Changed

- Configurations record their keyboard format and are converted automatically in
  both directions when changing Minecraft versions.
- A separate backup is saved before each format change. A combination containing
  an unsupported key is disabled, with details recorded in the game log.
- Invalid configurations or unknown config versions are preserved instead of
  being overwritten with defaults.

## Compatibility

- Available for Fabric on Minecraft 1.21.11, 26.1.x, 26.2, and 26.3.
- Install Soundboard 0.4.0 on every Minecraft version sharing the configuration;
  older Soundboard releases cannot convert the new keyboard format.

## Known issues

- F25 and other keys without an equivalent in the target version cannot be carried
  over. The original combinations remain available in the backup.
