# Simple Voice Chat Soundboard 0.3.1

Status: Draft

This release builds on 0.3.0.

## Added

- Added a global Sound Amplifier to General Settings. It is multiplied with
  every sound's individual amplifier and defaults to 100 percent.
- Added an interactive favorite star beside every sound and a favorite filter to
  Sound Settings.
- Added a clear empty state when the sound wheel has no favorites to display.

## Changed

- The sound wheel now displays only favorite sounds.

## Compatibility

- Available for Fabric on Minecraft 26.2, 26.1.x, and 1.21.11.
- Existing sound files and `config/soundboard.json` settings continue to be used.
